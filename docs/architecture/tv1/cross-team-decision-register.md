## Architecture review decisions

These are TV1 recommendations, not approval records. Phase 2A material on PR #6 describes directions for TV3's own work. It does not freeze team wire, migration or host contracts.

| Decision | TV1 recommendation | Evidence, dependencies and acceptance |
| --- | --- | --- |
| D-01 Modular monolith | **ACCEPT WITH CONDITIONS** | Fits one backend in technical supplement. #6 already has one bootstrap and Conversation/Groups packages. TV1 owns shared security/common, TV2/TV3 own domain services. Avoid repository coupling and cyclic modules. Prove one deployable and actual PostgreSQL tests (E9–E11, E13). |
| D-02 Shared Conversation UUID and Message pipeline | **ACCEPT WITH CONDITIONS** | Matches MASTER SPEC. V1 supports DIRECT/GROUP and Groups uses shared UUID. TV2 provides canonical pair, idempotent Messages and one pipeline. TV3 supplies membership policy, TV1 identity. No real Messages implementation in V1 (E7, E10). |
| D-03 Membership periods and latest-join history | **NEEDS REVISION** | Policy compatible as a proposal. Current schema can hold only one membership row per pair. Must define join/leave sequence bounds, fresh explicit invite after removal, migration/backfill and race tests. TV3 schema, TV2 history, TV1 privacy (E10, E13). |
| D-04 Least privilege, ACTIVE membership | **ACCEPT WITH CONDITIONS** | Existing Groups requires ACTIVE at group reads. Own pending invitation is a separate authorization surface and conveys no history. Expand checks to send, subscribe, delivery, media and translation. Test concurrent removal and concealed resources (E9–E10). |
| D-05 Transactional sequence | **ACCEPT WITH CONDITIONS** | Existing sources require ordering but have no server allocator. TV2 allocates per-conversation sequence in the message/idempotency transaction, enforces uniqueness, publishes after commit and tests races, rollback and lock contention. TV3 coordinates join boundary (E7, E10). |
| D-06 Local JWT and provider-independent principal | **ACCEPT WITH CONDITIONS** | UUID matches Session V2, current decoder uses issuer discovery. TV1 specifies signing, trust, refresh/revoke and REST/WS security before wiring. Managed issuer remains viable if mapped to the same principal (E2, E9). |
| D-07 REST/WS and distinct history/replay cursors | **NEEDS REVISION** | Groups page-based and Messaging draft sequence behavior do not define production wire. Provide examples, nullability, cursor/reset and gap behavior, replay ordering, membership filtering, envelope, read vs delivered semantics and tests. Full Messaging Wire Contract V1 is unavailable in current evidence (E7, E10). |
| D-08 | **INSUFFICIENT EVIDENCE** | The full D-08 decision was not supplied. TV3's new backend manifest references the label alongside immutable V1/forward changes. Treat that as a source reference and preserve migrations, pending the actual ADR, scope and approval record (E13). |
| D-09 TV1 shared security/principal | **ACCEPT WITH CONDITIONS** | Currently global beans located in Groups. TV1 supplies one common chain/principal/error contract, deny-by-default and claims checks. TV2/TV3 review domain usage and authorize in services (E9, E11). |
| D-10 App Shell/feature boundaries | **ACCEPT WITH CONDITIONS** | Current Home and feature ports fit split ownership. Pending real mount, host adapter, account teardown, async transport and acceptance semantics including UUID and epoch (E1, E4, E7–E8). |
